# README.md — Radio Community

This repository contains tools and configuration for managing radio community applications and services.

## Overview

Radio Community provides utilities for managing radio-related services, streams, and community features. It includes tools for monitoring, configuration, and integration with various radio platforms.

## Features

- 📻 **Radio Stream Monitoring** - Track live streams and broadcast status
- 🔧 **Service Configuration** - Manage radio service settings
- 📊 **Analytics** - View listener statistics and service health
- 🌐 **Integration** - Connect with various radio platforms and APIs

## Installation

```bash
# Clone the repository
git clone https://github.com/Aldo-f/radio-community.git
cd radio-community

# Install dependencies
npm install
# or:
pip install -r requirements.txt

# Configure environment
cp .env.example .env
# Edit .env with your service credentials

# Start the service
npm start
# or:
python main.py
```

## Docker

```bash
docker compose up -d
```
