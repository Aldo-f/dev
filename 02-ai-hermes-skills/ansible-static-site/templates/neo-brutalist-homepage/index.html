--- name: neo-brutalist-homepage description: "Template for a neo-brutalist server dashboard homepage." format: html+css --- # Neo-Brutalist Homepage Template This template creates a raw, bold, high-contrast dashboard showing server metrics. ## Features - Uptime display (human-readable) - RAM usage (used/total + percentage bar) - Disk usage (HDD1, SSD) - CPU load averages (1m, 5m, 15m) - CPU temperature - Project counter - Subsite links (auto-generated) ## Files ``` index.html - Main page with all metrics style.css - Neo-brutalist styling metrics.json - JSON data from collect-metrics.sh ``` ## Usage 1. Copy `index.html` and `style.css` to your site root 2. Replace metric values with actual data (via Ansible, SSI, or JavaScript fetch) 3. Deploy via Ansible playbook ## Styling Notes - No frameworks - No JavaScript for core content - 3px solid black borders everywhere - Monospace font (Courier New) - High contrast (black on white/cream) - No border-radius - Grid layout for metrics
