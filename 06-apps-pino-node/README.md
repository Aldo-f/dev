# README.md — Pino Node

**Node.js service for passive income monitoring**

## Overview

Pino Node is a lightweight Node.js application that monitors and manages passive income providers (Honeygain, Traffmonetizer, Earnapp). It provides a web API for tracking earnings, managing provider credentials, and viewing analytics.

## Project Structure

```
├── config/
│   └── docker-compose.yml
├── docs/
├── nodes/
├── providers/
│   ├── earnapp/
│   └── provider.json
├── scripts/
├── specs/
└── tests/
    ├── test_dashboard.py
    └── test_dashboard.sh
```
