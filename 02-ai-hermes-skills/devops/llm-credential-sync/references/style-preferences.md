# Style & interaction preferences

- **Concise English** – all output from this skill (CLI, dashboard, API) should be brief and in English.
- **Direct action style** – the skill should be usable with a single command (e.g., `bun run src/cli.ts --mode sync`) rather than step‑by‑step instructions.
- **Human‑verification UI** – the key‑generator UI includes a mandatory checkbox and optional `KEYGEN_TOKEN` protection.

These preferences reflect the user's desired workflow for the credential sync system.
