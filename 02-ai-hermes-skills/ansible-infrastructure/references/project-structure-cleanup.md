# Project Structure Cleanup Pattern

**Trigger**: When the 01-core-infra project root accumulates stale runtime copies and unorganized scripts that should be in templates or proper subdirectories.

**Session Context**: August 2026 - Cleaned up project root after media services deployment

## Problem Identified

The project root contained:
- Stale runtime copies: `plex/`, `qbittorrent/`, `nextcloud/` directories with outdated docker-compose.yml
- Unorganized scripts in `scripts/` root: `reload_traefik.sh`, `setup-mem0.sh`, `backup.sh`, `healthcheck.sh`, `podman-deploy.sh`
- Verification scripts in root: `verify_deployment.py`

## Cleanup Actions Performed

### 1. Remove Stale Runtime Copies
```bash
# These are generated by Ansible containers role - never edit manually
rm -rf /home/aldo/dev/01-core-infra/plex
rm -rf /home/aldo/dev/01-core-infra/qbittorrent
rm -rf /home/aldo/dev/01-core-infra/nextcloud
# Also removed portainer/ and cockpit/ stale copies
```

### 2. Organize Scripts into Subdirectories
```
scripts/
├── deploy.sh              # Main deployment (stays at root)
├── operations/            # Cron-driven maintenance
│   ├── backup.sh
│   └── healthcheck.sh
├── traefik/               # Traefik management
│   └── reload_traefik.sh
├── hermes/                # Hermes/mem0 management
│   └── setup-mem0.sh
└── podman/                # Podman deployment
    └── deploy.sh
```

### 3. Update All References
| File | Change |
|------|--------|
| `ansible/roles/cron/tasks/main.yml` | `src: "{{ infra_dir }}/scripts/operations/backup.sh"` |
| `templates/cron/01-core-infra.cron` | `__CORE_INFRA__/scripts/operations/backup.sh` |
| `ansible/tests/verify_equivalence.sh` | Updated expected paths |
| `docs/docs/deployment.md` | `scripts/operations/healthcheck.sh` |
| `docs/docs/reference.md` | Updated script paths in tables |
| `docs/docs/architecture.md` | Updated directory layout diagram |

### 4. Add Verification Infrastructure
```
tests/
├── verify_deployment.py    # Python runtime verification
├── verify.yml              # Ansible playbook verification
├── Dockerfile.pi3          # Updated to COPY scripts/, templates/, vaults/
├── Dockerfile.pi5          # Updated to COPY scripts/, templates/, vaults/
└── test-deploy.sh          # Existing test runner
```

## Verification Checklist After Cleanup

- [ ] No stale runtime directories in project root (`plex/`, `qbittorrent/`, `nextcloud/`, `portainer/`, `cockpit/`)
- [ ] All scripts organized in `scripts/<category>/`
- [ ] Cron templates reference new script paths
- [ ] Ansible roles copy from new script paths
- [ ] Documentation reflects new structure
- [ ] Test Dockerfiles include all necessary directories
- [ ] Verification scripts pass: `python3 tests/verify_deployment.py` && `ansible-playbook tests/verify.yml`

## Key Principle

**Templates in `templates/infra/<component>/` are the ONLY source of truth.** The Ansible containers role copies these to runtime directories at deploy time. Runtime copies in project root are stale artifacts that should be removed.
