# Optimize Internet Surfing on Raspberry Pi

This skill provides a comprehensive guide to enhance internet browsing speed and stability on your Raspberry Pi. It covers various aspects from DNS configuration to TCP tuning and browser choices.

## Key Optimization Areas:

- **DNS Resolution:** Improving the speed and reliability of domain name lookups.
- **Network Stack Tuning:** Adjusting parameters like MTU and TCP congestion control.
- **Local Network Services:** Leveraging tools like Pi-hole for caching and filtering.
- **Browser and Tooling:** Recommending efficient ways to access the internet.
- **System Maintenance:** Ensuring firmware and drivers are up-to-date.

Refer to the `references/optimization_guide.md` file for detailed steps and commands.
